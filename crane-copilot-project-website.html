What is Crane Copilot?

Three cooperating AI layers working together to keep a tower crane stable under dynamic wind and load conditions.

🎮

PPO RL Agent

A Proximal Policy Optimisation agent continuously controls the trolley position to maximise the crane's stability reserve — even under sudden wind gusts.

📈

LSTM Forecasting

Two LSTM networks predict structural tilt and stability margin ratio 500 ms – 1 second into the future using a 5-second sensor history window.

🚨

Early Warning System

A hybrid risk classifier combines LSTM predictions with current physics to raise SAFE / WARNING / CRITICAL / IMMINENT alerts with hysteresis debouncing.

⚙️

Physics Simulation

A forced damped pendulum model with Ornstein-Uhlenbeck wind, overturning/restoring moments, dynamic structural tilt, and real-time stability margin.

Risk Classification

The early warning system outputs one of four risk levels every 100 ms, smoothed by a hysteresis filter to prevent noisy flickering.

LevelMargin RatioTrigger ConditionResponse
SAFE > 0.35 No threshold crossed Normal operation
WARNING 0.20 – 0.35 2+ of: margin low, predicted low, tilt rate high, tilt high Operator alert — reduce load/speed
CRITICAL 0.08 – 0.20 2+ critical signals including LSTM +500 ms prediction PPO copilot takes active control
IMMINENT TIPPING < 0.08 2+ severe signals — margin collapse imminent Emergency retract — stop all operations

Hysteresis: escalates after 2 consecutive high-risk inferences · de-escalates after 5 consecutive safe inferences.

Key Improvements Made

10 targeted upgrades applied to the original codebase.

  • VecNormalize for PPO — normalises observations and rewards online, fixing the ±1e7 stability margin scale problem that destabilised gradient updates. train_ppo.py
  • Randomised reset() initial conditions — trolley, load, and swing angle are now randomly sampled each episode, preventing the agent from overfitting to a single fixed start state. crane_env.py
  • 1M timesteps + 8 parallel envs — 5× more training data vs the original 200k / 1 env configuration. train_ppo.py
  • Dataset 300 → 1,000 episodes — 938K rows vs original ~240K, dramatically improving LSTM generalisation. generate_dataset.py
  • Ornstein-Uhlenbeck wind model — replaced pure random walk with mean-reverting OU process; wind stays physically plausible over long episodes. wind.py
  • LSTM: hidden=128, 50 epochs, early stopping — doubled capacity, adaptive LR, Huber+MSE loss for robustness against rare tipping steps. train_lstm.py, train_risk_lstm.py
  • Removed reward hard-clip [-50, +10] — tipping penalty of -100 now propagates fully; recovery bonus capped at 2.0 to prevent single-step dominance. crane_env.py
  • Early warning switched to Risk LSTM — predicts margin_ratio directly instead of chaining through tilt prediction, reducing classification error. early_warning.py
  • Hysteresis debouncing — escalate after 2, de-escalate after 5 consecutive inferences; eliminates SAFE→WARNING flickering. early_warning.py
  • Shared models.py + data_utils.py — single source of truth for LSTM classes and split logic; no more silent drift between training and inference. models.py, data_utils.py

Quickstart

Run the full pipeline from scratch in order.

# 1. Launch Interactive 3D Simulation (Browser WebGL) python visualize_crane_3d.py --web # 2. Launch Native Python 3D Simulation (Matplotlib 3D) python visualize_crane_3d.py # 3. Generate 1,000-episode sensor dataset python generate_dataset.py # 4. Train structural tilt & risk LSTMs python train_lstm.py python train_risk_lstm.py # 5. Train PPO copilot agent (1M steps, ~1-2 hrs on CPU) python train_ppo.py # 6. Evaluate early warning system python early_warning.py # 7. Benchmark PPO vs HOLD vs INWARD controllers python evaluate_ppo_copilot.py

After first PPO training run: set PPO_EPISODE_FRACTION = 0.4 in generate_dataset.py, regenerate the dataset, and retrain LSTMs for best results.
